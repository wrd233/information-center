# 信息中心作战台 — 操作指南

## 1. 第一次打开页面应该做什么？

打开 `http://127.0.0.1:8788`，你会看到**作战首页**（Dashboard）。

首页顶部显示四项关键状态：
- **环境状态**：是否为 Fresh DB（工作区），是否安全
- **信息源数量**：已有多少个 RSS/Atom 源
- **原始信息数量**：当前数据库中有多少条抓取的信息
- **抓取任务数量**：已执行过多少次任务

**下一步建议**区域会根据当前状态智能推荐操作。例如：
- 如果还没有信息源 → "导入 source"
- 如果有信息源但没有任务 → "创建 dry-run"
- 如果 dry-run 已完成 → "执行 real-write"

## 2. 如何导入信息源？

进入**信息源管理**（/sources），有三种方式：

### 方式 A：批量导入（推荐）
1. 在"批量导入信息源"卡片中选择格式（每行 URL / CSV / JSON / OPML）
2. 粘贴导入内容
3. 点击"预览导入"查看将要新增、重复、无效的条目
4. 确认无误后点击"确认导入"

### 方式 B：新增单个 RSS
1. 在"新增单个信息源"卡片中输入 RSS/Atom URL
2. （可选）填写名称和分类
3. 点击"检查信息源"验证 URL 可用性
4. 如果可用且不重复，点击"确认新增信息源"

### 方式 C：导出再导入
在"导出信息源"卡片中导出当前注册表为 OPML，修改后重新导入。

## 3. 如何先 dry-run（预演）？

1. 进入**创建抓取任务**（/runs/new）
2. **第 1 步**：选择"预演模式（dry-run）"——默认推荐
3. **第 2 步**：选择信息源范围（推荐"全部活跃信息源"）
4. **第 3 步**：设置时间范围（留空则不限制）
5. **第 4 步**：设置规模限制（默认 20 源 × 20 条 = 200 条上限）
6. 点击"预览任务"→ 查看影响范围
7. 在预览页确认无误后，点击"确认启动"

预演模式不会向数据库写入任何条目。它用于验证信息源可用性和抓取范围。

## 4. 如何 real-write（写入）？

1. 确保后端已设置 `CONTENT_INBOX_ENABLE_REAL_RUNS=1`
2. 预演确认无误后，回到创建任务页
3. **第 1 步**：选择"写入模式（real-write）"
4. 使用与预演相同的信息源和时间设置
5. 预览后启动

## 5. 如何观察任务？

进入**任务驾驶舱**（/runs/{run_id}），可以看到：

- **状态头部**：任务 ID、状态、模式、耗时
- **关键指标**：信息源数、写入条目数、重复/失败数
- **下一步建议**：根据当前状态推荐后续操作
- **信息处理流程**：去重 → 语义 → 聚合 → 事件 → 审核 → 简报 → 报告，各阶段可独立运行
- **事件时间线**：实时显示任务的每个步骤
- **信息源进度表**：每个信息源的抓取/写入/失败统计
- **写入条目列表**：本次任务写入的具体信息

任务运行中时，状态和时间线会每 5 秒自动刷新。

## 6. 如何把原始信息处理成事件？

在任务驾驶舱的**信息处理流程**区域，依次点击各阶段的"运行"按钮：
1. **去重**：发现并合并重复条目
2. **语义**：提取实体、声明、证据
3. **聚合**：生成聚合线索
4. **事件**：生成候选事件
5. **审核**：生成待审核项
6. **简报**：生成每日简报
7. **报告**：生成详细报告

每个阶段运行后，状态指示器会从"待处理"变为"完成"。

## 7. 如何审核？

进入**待审核**（/review-queue），你会看到流水线生成的候选事件列表。

每个审核卡片显示：
- 审核类型
- 系统建议
- 目标对象
- 操作按钮：**确认**和**忽略**

点击"确认"表示接受该候选事件，点击"忽略"表示暂不处理。

## 8. 如何生成简报和报告？

### 简报（Briefing）
进入**简报**（/briefings）页面，点击"生成每日简报"。简报基于已有事件和待审核项自动生成。

### 报告（Report）
进入**报告**（/reports）页面，选择报告类型：
- **总体摘要**：系统状态总结
- **信息源健康度**：信息源可用性报告
- **事件报告**：事件详情报告

点击"生成报告"即可。

## 9. 如何清空部分数据重新开始？

进入**数据清理**（/reset）页面，选择清理范围：

| 范围 | 说明 | 风险 |
|------|------|------|
| 保留信息源，清空抓取内容和运行记录 | 用同一批源重新抓取 | 高 |
| 保留原始信息，重跑语义/聚合/事件 | 修改流水线后重新处理 | 中 |
| 只清空简报/报告/智能查询输出 | 重新生成输出 | 中 |
| 清空某个任务的结果 | 某次任务跑错了 | 高 |
| 清空某些信息源及下游内容 | 删除低质量来源 | 高 |
| 全部清空并重新开始 | 完全重新开始 | 严重 |

所有操作流程：**选择目标 → 预览影响 → 输入确认文本 → 提交**。

## 10. 哪些页面是高级调试页？

以下页面是高级调试视图，普通使用流程不需要访问（它们在侧边栏"高级调试"分组中，默认折叠）：

- **原始信息列表**（/items）：直接查看数据库中的原始条目
- **去重组**（/dedupe-groups）：查看去重规则匹配结果
- **聚合线索**（/clusters）：查看自动聚合的信息簇
- **实体**（/entities）、**关系**（/relations）、**断言**（/claims）、**主题**（/topics）：语义提取结果
- **时间线**（/timeline）、**证据**（/evidence）、**视图**（/saved-views）：辅助调试视图
