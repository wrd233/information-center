## 5. Same-Event Recall Repair

Implemented three conservative candidate lanes:

- `same_source_repeat`: same non-empty source, exact event signature match, actor/product/action match, close time window, and no hard precision disqualifier. This upgrades high-confidence same-source repeats to `high`.
- `cross_source_same_product`: different sources, event signatures on both sides, same actor/product/action, within 7 days, and no hard precision disqualifier. Pairs inside 72h can be high; wider 7-day pairs stay `medium` for review rather than automatic merge.
- `cross_language_alias`: cross-language pair with alias-normalized actor/product match, event signatures on both sides, close time window, and no hard precision disqualifier. Exact signature plus same action can be `must_run`; action-mismatch cases stay `medium` for review.

Tests cover:

- same-source repeat recall
- same-source different-product rejection
- cross-source same-product review-window recall
- cross-language alias recall

Precision guard behavior was kept in `operational_pipeline._relation_from_candidate`; medium candidates still require review, and hard negatives are still excluded.
